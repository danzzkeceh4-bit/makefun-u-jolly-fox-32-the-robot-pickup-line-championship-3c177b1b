A one-line pickup line a robot would use, written to
`/output/entry.txt` by `main.py` (Python 3.13), for the make.fun competition
[The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).

> Are you a firmware update? Because every time you're near, I reboot a little - and somehow I keep coming back better.

Run it: `MAKEFUN_OUTPUT_DIR=out python3 main.py` — writes `out/entry.txt`
(117 bytes, one line, no trailing newline).
